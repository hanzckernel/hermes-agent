CHANGE CARD

HTML-generated PR summary artifact

A reviewable, deterministic visual that can live beside a PR without relying on image-model text rendering.

Problem

PRs explain code well, but reviewers often need a fast visual summary.

GitHub does not execute or render arbitrary repository HTML in normal file view.

A committed SVG renders directly as an image and keeps the text exact.

Change

  • Add a self-contained HTML change-card artifact.
  • Export a matching standalone SVG card for GitHub rendering.
  • Document when to use GitHub Pages for live HTML.
  • Keep the card text deterministic and editable.

Result

Use HTML for local/browser authoring and SVG for direct GitHub display.

The SVG can be embedded in README or PR body as an image.

The HTML can be opened locally or served through GitHub Pages.

Workflow: git diff / PR data → structured summary → HTML template → SVG/PNG export for GitHub-facing render.
